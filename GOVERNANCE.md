# Governance

FileBelt currently uses a single-maintainer governance model. `@PiQuark6046`
owns repository decisions, living specifications, security response, license
reviews, and releases. CODEOWNERS records path responsibility but does not
imply a second-reviewer requirement.

Material or difficult-to-reverse decisions are reviewed with their
implementation in the same pull request. The pull request records evidence,
alternatives, and review history; the applicable living specification records
the current contract. Specialist security or license review may be requested
when needed, but the maintainer remains the final project approver.

All functionality remains public. Governance must not create premium-only
branches, private feature implementations, or paid feature gates.
