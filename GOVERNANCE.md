# Governance

FileBelt currently uses a single-maintainer governance model. `@PiQuark6046`
owns repository decisions, accepted ADRs, security response, license reviews,
and releases. CODEOWNERS records path responsibility but does not imply a
second-reviewer requirement.

Material or difficult-to-reverse decisions are recorded as ADRs. Accepted ADRs
are never rewritten to conceal a changed decision; a later ADR supersedes
them. Specialist security or license review may be requested when needed, but
the maintainer remains the final project approver.

All functionality remains public. Governance must not create premium-only
branches, private feature implementations, or paid feature gates.
