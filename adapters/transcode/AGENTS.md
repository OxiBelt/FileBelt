# Transcode adapter guidance

Only Apache-2.0 governance files are permitted here during Phase 0. Do not add
source, a build manifest, FFmpeg configuration, binary, or image definition
until an accepted ADR records exact upstream revisions, configure flags,
linkage, GPL/LGPL expression, replacement obligations, notices, source mapping,
and per-platform functional tests.
